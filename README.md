# SpendWise Dashboard Shell

SpendWise is a responsive personal finance dashboard shell built using HTML and modern CSS layout techniques.

## Files

* `index.html` — Contains the dashboard structure, navigation, header, financial summary, spending cards, and recent transactions.
* `style.css` — Provides the responsive layout, CSS Grid and Flexbox styling, custom properties, card interactions, and dark theme.
* `README.md` — Explains the project and its files.

## Features

* CSS Grid for the main dashboard and card layouts.
* Flexbox for navigation, headers, cards, and transaction content.
* Six financial category cards: Food, Transport, Rent, Entertainment, Savings, and Utilities.
* CSS custom properties for the application's theme.
* Responsive single-column layout below 768px.
* Hover and keyboard-focus micro-interactions on dashboard cards.
* Automatic dark theme using `prefers-color-scheme: dark`.
* No absolute positioning is used for the page layout.
